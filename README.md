# H4DF Android App

H4DF is an Android starter project for organizing files and documenting file metadata for coursework and authorized evidence-handling workflows.

## Build
The GitHub Actions workflow will build a debug APK and upload it as an artifact.

## Features planned
- Create a case label
- Choose files through Android's system file picker
- Calculate SHA-256 file hashes
- Save a local metadata register
- Export a register for documentation

Only use files you are authorized to access. This app does not perform background collection or covert recording.
